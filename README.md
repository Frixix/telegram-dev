# Telegram Dev Agent 🚀

Sistema de automatización y desarrollo asistido por IA controlado desde Telegram.

La idea principal es poder programar, modificar, desplegar y supervisar proyectos web directamente desde el celular mediante comandos enviados a un bot.

# Objetivo principal

Construir un sistema donde:

```text
Telegram
↓
Agente IA
↓
Modificación de código
↓
GitHub
↓
Deploy automático
↓
Vista online actualizada
```

Todo controlado desde cualquier dispositivo, especialmente desde el celular.

---

# Filosofía del proyecto

Este proyecto busca:

- Reducir fricción al programar
- Permitir desarrollo móvil
- Automatizar tareas repetitivas
- Integrar IA con flujos reales de desarrollo
- Crear agentes autónomos controlados por lenguaje natural
